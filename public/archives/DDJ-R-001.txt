FILE R-001 / 遗忘核在信念动态系统中的作用模拟（研究生毕论）
COLLECTIVE FORGETTING IN OPINION DYNAMICS

角色：硕士毕业论文
时期：2024.09 - 至今
技术栈：DeGroot 模型 / Python / 仿真分析
访问范围：OPEN SOURCE

基于 DeGroot 模型引入遗忘核参数，仿真分析个体记忆衰减对群体共识形成的影响，发现中等遗忘强度可显著缩短共识时间，且该效应在不同网络结构下稳健。

详细记录
1. 研究问题：个体记忆衰减（遗忘）如何影响群体共识的形成过程。
2. 实验设计与数据生成：控制网络拓扑、遗忘强度、初始意见分布，生成多条件时序面板数据。
3. 指标构建：选取共识达成时间、意见方差衰减率、振荡幅度等指标量化遗忘核影响，搭建可复用分析框架。
4. 统计建模与可视化：Python 清洗与聚合仿真数据，经分组对比和趋势拟合，绘制收敛曲线与热力图，揭示遗忘强度与共识速度的非线性关系。
5. 核心发现：中等遗忘强度可显著缩短共识时间，且该效应在不同网络结构下稳健——提炼“适度遗忘促进共识”的结论，为记忆机制与传播研究提供量化依据。
