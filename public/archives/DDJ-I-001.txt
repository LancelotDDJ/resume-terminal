研发部 AI 实习生：负责 AI 游戏创造工坊的 AI/Agent 模块（Agent 编排、多模型接入、流式对话与内容安全），并独立交付电商信息智能采集与商家评估 Agent，两条业务线并行推进。

详细记录
1. 实习总览：负责 AI 游戏创造工坊的 AI/Agent 模块并参与前后端联调与部署；电商采集 Agent 从需求分析到设计、开发、交付独立完成。
2. AI 游戏创造工坊 · 平台简介：面向青少年的一站式 AI 创作平台，孩子通过自然语言对话即可生成可运行的小游戏、编写故事、创作绘画与代码，配套家长中心、好友社交与技能成长体系。
3. 多 Agent 游戏生成流水线：设计并实现“自然语言需求 → 可运行游戏”的 Agent 编排，覆盖意图分类、需求优化、游戏生成、安全审查、内容过滤、封面生成等节点；提示词与模型参数全部 JSON 配置化，支持运行时热切换。
4. 多模型统一接入与流式对话：统一 LLM 客户端以协议适配方式同时支持 Anthropic 与 OpenAI 兼容 API，按配置切换 DeepSeek / MiniMax / GLM；基于 SSE 实现逐字流式输出，以“请求体保存 + 失败重试 + 双游标增量读取”解决长文本传输的中断与重复，并以聊天总结 Agent 控制多轮对话成本。
5. AI 内容安全三重防线：安全审查、内容过滤与图片审核分层拦截；修复“孩子跳过等待动画导致未审核作品被展示”的线上漏洞，补全前后端状态校验，保障未成年人内容安全。
6. 电商信息智能采集与商家评估 Agent：面向 3C 电商推广素材业务的售前获客需求，输入淘宝/天猫搜索页 URL 与品类关键词，自动完成采集 → 清洗分类 → 大模型企业信息查询 → 多维评估全流程，输出带客户优先级排序的交互式 HTML 报告。
7. 五阶段采集管道与反爬攻克：基于 Playwright + asyncio 异步编排，长任务支持断点续跑与运行时暂停/继续/跳过；JS 注入伪造浏览器指纹、持久化登录态复用、骨架屏轮询感知、DOM 层级自适应爬升与 ARIA 分页定位，实现不依赖特定 CSS 选择器的鲁棒采集。
8. 多维度商家评分模型：综合销量适配、品牌独立、地域商业化、内容需求、品类匹配、店铺体量六因素加权，输出 S~D 五级客户优先级排序，直接为商务团队提供线索筛选依据，已覆盖多个品类。
