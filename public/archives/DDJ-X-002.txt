FILE X-002 / 跨境电商用户及舆情洞察自动化分析系统
COUPANG REVIEW ANALYSIS

角色：独立开发 · 自动化分析系统
时期：2026.06
技术栈：Python / NLP / 浏览器自动化
访问范围：OPEN SOURCE

面向韩国主流电商平台，构建从商品评价采集、多语言 NLP 分析到竞品对比报告生成的端到端自动化系统，输出交互式 HTML 竞品洞察报告。

详细记录
1. 数据采集：分析平台通信机制，通过浏览器自动化绕过反爬限制，稳定获取商品全量评价数据（含评分、文本、时间戳等完整字段）。
2. 多语言 NLP 与情感建模：评分分层分析策略——负评逐条归因、中评抓转折词挖掘隐含不满、好评按有用数排序提炼卖点；提取高频关键词归纳为 5-6 类话题，计算情感倾向值，构建用户旅程情绪热力图。
3. 竞品对比框架：双产品维度独立展示并附多维综合雷达图，覆盖总体评分、情感占比及核心属性满意度。
4. 报告生成：Python 报告生成器输出独立交互式 HTML，关键外文内容附中文对照，无需服务端即可查看；完整流程封装为可复用工具，支持单品分析与竞品对比两种模式自动切换。
