FILE P-006 / AI 智能聊天手机软件
AI CHAT APP

角色：独立开发 · Android 应用
时期：2022.11 - 2023.05
技术栈：Kotlin / Android / WENXIN 1.1 API
访问范围：PUBLIC

基于 Android 端集成大语言模型 API，开发轻量级 AI 聊天应用：把模型推理放在云端、本地只负责交互，以此绕开移动设备的算力与内存瓶颈。压力测试支持 1000+ 并发，响应延迟控制在 400ms 以内。

详细记录
1. 应用开发：使用 Kotlin 完成 Android 端开发，接入 WENXIN 1.1 大模型 API，实现智能对话功能与完整会话流程。
2. 架构选择：采用“云端算力 + 轻客户端”思路，把模型能力放在服务端，移动端专注于交互与状态管理，规避端侧算力不足导致的体验下降。
3. 交互设计：设计简洁直观的对话界面，优化输入、等待与结果呈现流程，提升易用性与视觉体验。
4. 性能表现：压力测试支持 1000+ 并发，响应延迟控制在 400ms 以内，整体响应速度与交互体验达到或超过同期同类商业应用水平。
