FILE P-003 / 跨境电商用户及舆情洞察自动化分析系统
COUPANG REVIEW ANALYSIS

角色：独立开发 · 自动化分析系统
时期：2026.06
技术栈：Python / 韩文 NLP / 反爬工程 / Chart.js
访问范围：OPEN SOURCE

面向韩国主流电商平台 Coupang，构建从商品评价全量采集、韩文 NLP 分析到竞品对比报告生成的端到端系统，输出交互式中文化 HTML 竞品洞察报告。已实测跑通三个真实商品（评价量 312 - 932 条），形成可复用工具，支持单品分析与竞品对比两种模式。

详细记录
1. 反爬数据采集：通过 HAR 逆向分析平台通信机制，定位 Coupang /next-api/review 内部接口，配合浏览器控制台脚本绕过 Akamai 反爬限制，稳定获取商品全量评价（评分、文本、时间戳等完整字段），单个商品可达 900+ 条。
2. 数据清洗管道：韩文日期解析、去重与字段完整性验证，异常样本单列，保证进入分析环节的数据口径统一。
3. 多语言 NLP 与情感建模：设计评分分层逐条阅读框架——负评精读逐条归因、中评抓转折词挖掘隐含不满、好评按有用数排序抽样提炼卖点；提取高频关键词并归纳为 5-6 类话题，计算情感倾向值。
4. 痛点与 VOC 体系：归纳 6 大痛点类别（AI 回避 / 品质 / 机身损伤 / 售后 / 地面损伤 / 其他），建立韩中双语关键词映射，使韩文原声与中文结论一一对应。
5. 用户旅程地图：按认知 → 购买 → 配送 → 开箱 → 使用 → 售后 6 个阶段构建情绪热力图，直观呈现体验断点发生在哪个环节。
6. 竞品对比框架：双产品各维度完全独立、并排展示并以视觉标识区分，末尾附多维度综合雷达图（总体评分、情感占比、核心属性满意度）；双产品维度独立避免了单一指标被平均掩盖的问题。
7. 报告生成：Python 报告生成器输出独立交互式 HTML（Chart.js v4 渲染），全中文表述、关键外文内容附中文对照，无需服务端即可打开查看与交付。
8. 工程化封装：完整流程封装为可复用工具（Claude Skill 主调度入口 + 采集/分析/报告三个独立脚本 + DOM 与 NLP 参考文档 + HTML 模板），支持单品分析与竞品对比两种模式自动切换，可快速迁移到其他平台或品类。
9. 实测案例：Roborock S10 MaxV Ultra（353 条 / 4.78 分，核心痛点 AI 障碍物回避、品质耐久、机身损伤）、Roborock F25 Ultra（312 条 / 4.89 分，痛点电池续航、机身重量、噪音）、Shark EVO POWER SYSTEM NEO+（932 条 / 4.82 分，痛点噪音、品质故障、二手发货）。
