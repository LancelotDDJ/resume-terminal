FILE X-001 / Voyager 海外旅行全生命周期管理应用
VOYAGER · TRAVEL ASSISTANT

角色：独立开发 · 双端应用
时期：2026.07 - 至今
技术栈：Electron / Capacitor / React / DeepSeek
访问范围：FEATURED

独立完成双端旅行管理应用的全链路开发。物理隔离的双工程架构共享 React 前端，集成 DeepSeek 大模型与本地知识检索，覆盖行前规划、旅行中监控、应急备份到行后归档的完整旅行生命周期，数据纯本地存储。

详细记录
1. 双端架构设计：基于 Electron 与 Capacitor 构建双端应用，共享 React 源码但物理隔离为独立工程；设计跨平台存储抽象层，统一封装 IPC、Filesystem 与 localStorage 三端数据接口，一套代码双端运行。
2. AI 能力集成：接入 DeepSeek 大模型 API，实现对话式旅行助手、行程智能生成与多城市路线优化；设计多层健壮 JSON 解析器并配合失败自动重试，解决大模型输出不稳定问题。
3. 本地知识检索（RAG）：设计关键词加权评分检索器，检索结果注入 AI 提示词，使行程生成与问答基于本地真实数据而非模型编造。
4. 多模态信息导入：自研零依赖解析器提取文本；集成 tesseract.js 本地中文 OCR 与视觉模型双轨识别图片行程单，AI 结构化提取后一键生成行程。
5. 局域网跨端同步：基于 Node 内置 HTTP 服务设计零依赖同步服务器，二维码扫码配对、updatedAt 时间戳增量同步、tombstone 删除传播与 last-write-wins 冲突解决；同步链路通过 6 项端到端测试。
