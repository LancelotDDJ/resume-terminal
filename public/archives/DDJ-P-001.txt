FILE P-001 / 个人简历终端网站（本站）
PERSONAL ARCHIVE TERMINAL

角色：独立开发 · 本网站
时期：2026.09
技术栈：TypeScript / Three.js / Vite
访问范围：PUBLIC

以三维档案终端形态呈现的个人简历网站：六列循环档案阵列承载个人简介、教育、实习、项目、科研与技能档案，支持检索、收藏、360° 模型查看与 TXT 导出，纯静态部署。

详细记录
1. 基于开源三维终端界面工程（MIT 许可）改造：保留循环阵列、解密动效、画质分级与音频架构，去除开场动画与全部第三方 IP 元素。
2. 内容数据与代码完全分离：全部简历内容维护在单一 JSON 数据文件中，校验与导出脚本保障一致性。
3. 工程特性：无后端、无 API Key、纯静态构建；支持减少动态效果偏好、四档画质分级、TXT 档案导出。

相关链接：https://github.com/LancelotDDJ
